# Installer BMAD

## 2026-10-31 kl. 13:01 — Caroline Grundekjøn

### Oppgave
Få BMAD-rammeverket inn i dette prosjektet, slik at det kan brukes med Claude Code i VS Code.

### Plan
- Sjekke git-status, `.gitignore` og eksisterende `.claude/` før installasjon.
- Installere `bmad-method@6.12.4` med modulen `bmm` for Claude Code, på gjeldende gren (`test`).

### Resultat
- BMAD 6.12.4 er installert i `_bmad/`, med 29 ferdigheter i `.claude/skills/`. Språk er satt til norsk.
- `sesjonslogg`-skillen er beholdt. `_bmad/` og `.claude/` er git-ignorert, så installasjonen gir ingen endringer i git.
- Claude Code-utvidelsen (v2.1.314) er installert i VS Code.
- `bmad-help` er testet fra Claude-appen: ferdigheten starter, men `uv run _bmad/scripts/resolve_config.py` feilet først med «Missing expected target directory for Python minor version link». Etter `uv python install 3.14 --reinstall` virker skriptet fra appen, selv om selve installasjonskommandoen fortsatt avslutter med samme feil. Ikke testet i VS Code.
- BMAD peker nå til `.docs/` via `_bmad/custom/config.toml` (bekreftet med `resolve_config.py`).

### Åpne punkter
- `uv run` er ikke testet i VS Code-terminalen. Python ble installert fra Claude-appen og er kanskje ikke synlig der.
- Hvert gruppemedlem som installerer BMAD, må selv legge inn `.docs`-stiene i `_bmad/custom/config.toml`, siden `_bmad/` er git-ignorert.
