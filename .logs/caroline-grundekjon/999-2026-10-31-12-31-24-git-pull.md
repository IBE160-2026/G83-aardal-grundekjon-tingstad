# Git-pull

## 2026-10-31 kl. 12:31 — Caroline Grundekjøn

### Oppgave
Kjøre `git pull` i prosjektet for å hente siste endringer fra origin.

### Plan
- Kontrollere arbeidskopi og aktiv branch.
- Kjøre `git pull` og dokumentere resultatet.

### Resultat
Arbeidskopien var ren på branch `test`. `git pull` rapporterte «Already up to date» for `origin/test`, og hentet samtidig den nye remote-branchen `origin/Test`.
