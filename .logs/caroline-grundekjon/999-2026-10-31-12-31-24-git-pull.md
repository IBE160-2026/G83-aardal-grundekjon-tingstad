# Git-pull

## 2026-10-31 kl. 12:44 — Caroline Grundekjøn

### Oppgave
Kjøre `git pull` i prosjektet for å hente siste endringer fra origin.

### Plan
- Kontrollere arbeidskopi og aktiv branch.
- Kjøre `git pull` og dokumentere resultatet.

### Resultat
Arbeidskopien var ren på branch `test`, som fortsatt er 7 commits foran `origin/test`. `git pull` rapporterte «Already up to date» for `origin/test`. Fetch oppdaget remote-branchen `test` og oppdaterte `origin/main` fra `e2d3bc8` til `95db228`; ingen endringer ble trukket inn i aktiv branch.
